1. 개요

갯길안(HaerujilSafe, 이하 “앱”)은 갯벌·연안 활동 시 물때·날씨·궤적·일지 등을 기기의 기능을 활용해 돕는 앱입니다. askkorandolab이 운영합니다.

앱은 사용자 계정을 만들지 않으며, 광고·분석(트래킹) SDK를 포함하지 않습니다. 개인 위치·궤적·스팟·일지를 개발자가 운영하는 서버에 올려 보관하지 않습니다.

2. 기기에서 다루는 정보

앱 기능을 위해 기기에서 다룰 수 있는 정보는 예를 들면 다음과 같습니다.

  • 위치·궤적: 세션·귀환·스팟 후보 등. 기본 저장 위치는 이 기기입니다.
  • 수확 스팟·위험/회피 표시·그날 일지: 사용자가 저장한 기록. 이 기기에만 남습니다.
  • 사진·학습용 이미지(해당 기능 사용 시): 기기 저장이 기본이며, 위치 포함은 기본으로 꺼져 있을 수 있습니다.
  • 센서·동작(해당 기능 사용 시): 동작·손목 움직임 등은 코칭·후보 안내용으로 기기에서 처리합니다.

“이 기기만 저장”이 기본이며, 실시간으로 위치를 서버에 스트리밍하지 않습니다. 구조 신호(화면·손전등 점멸·소리)도 좌표를 서버로 올리지 않습니다.

3. 외부로 나갈 수 있는 요청 (개인정보 DB가 아님)

물때·날씨·교통 등 공공·시스템 정보를 보여 주기 위해, 기기가 직접 공공 API 또는 Apple 시스템 API에 요청할 수 있습니다. 예시(연동·가용 여부는 기기·지역·권한에 따라 다름):

  • 해양 관련 공공 정보(예: KHOA 연동)
  • 날씨(예: WeatherKit)
  • 교통·도로 정보(예: ITS, 도로공사 등)

이는 기기가 해당 서비스에 필요한 범위의 요청을 보내는 것이며, askkorandolab이 사용자의 개인 위치·일지를 수집해 별도의 개인정보 DB를 운영하는 것이 아닙니다. 각 외부 서비스의 처리 방침은 해당 제공자를 따릅니다.

4. 사용자가 직접 보내는 공유

친구 공유, 구조 문자, 시스템 공유 시트 등은 사용자가 기기에서 직접 보낼 때만 이루어집니다. 앱이 백그라운드에서 자동으로 위치를 제3자에게 실시간 공유하지 않습니다.

5. 구조·긴급

위급 시 구조 요청은 119 등 공식 긴급 채널을 이용하세요. 앱의 점멸·소리·안내는 기기 위 보조 기능이며, 구조를 대행하거나 위치를 구조 기관 서버로 자동 전송하지 않습니다.

6. 보관·삭제

기기 내 기록은 사용자가 앱·기기 설정에서 삭제하거나 앱을 삭제하면 해당 기기에서 함께 제거되는 것이 일반적입니다. 개발자 서버에 개인 위치·일지 DB를 두지 않으므로, 서버측 “계정 삭제” 절차는 해당되지 않습니다.
